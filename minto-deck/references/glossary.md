# Glossary (EN / DE)

Fixed term pairs. Use the English term with the German gloss on first use in a
German deck's commentary and notes; on the slides themselves use only the deck
language. Add pairs here when a new term appears in a project.

| Pyramid Principle | Pyramidenprinzip | method name, keep English in commentary |
| governing thought | Kernbotschaft, Hauptaussage | the one answer the deck gives |

| SCQA (situation, complication, question, answer) | SCQA (Situation, Komplikation, Frage, Antwort) | opening structure |
| action title | Aussagetitel, Handlungstitel | full-sentence slide title |
| topic title | Themenüberschrift | what an action title is not |
