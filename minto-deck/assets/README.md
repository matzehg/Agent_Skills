# Assets

Holds the approved reference deck once one exists and the synthetic template
for tests. Keep every folder here at most one level deep: some skill loaders
(GitHub Copilot) refuse deeper trees.

- `reference-deck/`: the first approved test run (ghost deck, deck, notes,
  timing plan, Q&A document, handout). Use it as a pattern for format and
  density only; never reuse its content. Empty until a run is approved.
- `synthetic-corp.pptx`: a stand-in corporate template for tests and evals,
  generated by `scripts/make-synthetic-template.js`: own palette (ACME
  Synthetic) and fonts (Georgia, Verdana), logo mark, footer, slide number,
  four layouts (Cover, Section, Content, Content 2 Columns). The last layout
  carries two body placeholders on purpose: the template path must delete
  them, never fill them.

Real company templates never go here. They stay outside public repositories,
and what the skill needs to know about them (layouts, body zone, colour
roles) lives in a private companion skill (`references/template-mode.md`
section 5).
